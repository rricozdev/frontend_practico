# 📘 Clase 2: Redux Toolkit – Controlando el caos moderno del estado

---

## ✨ 0. Motivación: ¿Por qué necesitamos algo como Redux Toolkit?

Las aplicaciones frontend modernas no solo muestran datos. Hoy debemos manejar cosas como:

* Respuestas del servidor (productos, usuarios, etc.).
* Datos locales temporales (inputs, selects, etc.).
* Estado de la UI (modales, spinners, tabs activos).
* Comportamiento asincrónico (cargando datos, errores, etc.).

Todo esto hace que manejar el estado en una app se vuelva **complejo**. A veces, un componente cambia un dato que afecta otro, que actualiza una vista, y ya no sabemos **qué pasó ni cuándo**.

> 🚀 Mezclar **mutación** y **asincronía** es como mezclar **Mentos y Coca-Cola**: separados, todo bien. Juntos... caos.

---

## ⚠️ El lío con Redux clásico

Redux fue una solución genial: todo pasa por un store, con reducers y acciones claras. Pero a medida que las apps crecen, el Redux clásico también trae problemas:

* Mucho **código repetido** (acciones, constantes, switch).
* Reducers grandes y poco legibles.
* Middleware y DevTools configurados a mano.

Entonces aparece...

---

## ✅ Redux Toolkit (RTK)

Es la **forma oficial y moderna** de usar Redux hoy en día. Fue creado por el mismo equipo de Redux para simplificar el proceso.

### Ventajas:

* Menos archivos.
* Reducers más claros.
* Acciones automáticas.
* Mutaciones "seguras" gracias a `immer`.
* DevTools y Thunk integrados por defecto.

---

## 🔄 Comparación práctica

| Etapa      | Redux Clásico                             | Redux Toolkit                             |
| ---------- | ----------------------------------------- | ----------------------------------------- |
| Store      | `createStore()`                           | `configureStore()`                        |
| Reducer    | `switch(action.type)`                     | `createSlice()`                           |
| Acciones   | Manuales y separadas                      | Automáticas dentro del slice              |
| DevTools   | Se configuran con `window.__REDUX...`     | Ya vienen activadas                       |
| Mutaciones | No se pueden hacer directas (usar spread) | Puedes usar mutaciones directas (seguras) |

## 📅 Ejemplo práctico: contador en ambas versiones

### 🧳 Redux Clásico

#### actions.js

```js
export const INCREMENTAR = "INCREMENTAR";
export const DECREMENTAR = "DECREMENTAR";
```

#### reducer.js

```js
import { INCREMENTAR, DECREMENTAR } from "./actions";

const initialState = { value: 0 };

function contadorReducer(state = initialState, action) {
  switch (action.type) {
    case INCREMENTAR:
      return { ...state, value: state.value + 1 };
    case DECREMENTAR:
      return { ...state, value: state.value - 1 };
    default:
      return state;
  }
}

export default contadorReducer;
```

#### store.js

```js
import { createStore, compose } from 'redux';
import contadorReducer from './reducer';

const composeEnhancers = window.__REDUX_DEVTOOLS_EXTENSION_COMPOSE__ || compose;
const store = createStore(contadorReducer, composeEnhancers());

export default store;
```

#### Contador.jsx

```jsx
import { useSelector, useDispatch } from 'react-redux';
import { INCREMENTAR, DECREMENTAR } from '../redux/actions';

function Contador() {
  const valor = useSelector(state => state.value);
  const dispatch = useDispatch();

  return (
    <div>
      <h2>Contador: {valor}</h2>
      <button onClick={() => dispatch({ type: INCREMENTAR })}>+</button>
      <button onClick={() => dispatch({ type: DECREMENTAR })}>-</button>
    </div>
  );
}

export default Contador;
```

### 🧠 Redux Toolkit

#### contadorSlice.js

```js
import { createSlice } from '@reduxjs/toolkit';

const contadorSlice = createSlice({
  name: 'contador',
  initialState: { value: 0 },
  reducers: {
    incrementar: (state) => { state.value++ },
    decrementar: (state) => { state.value-- },
  }
});

export const { incrementar, decrementar } = contadorSlice.actions;
export default contadorSlice.reducer;
```

#### store.js

```js
import { configureStore } from '@reduxjs/toolkit';
import contadorReducer from './features/contadorSlice';

export const store = configureStore({
  reducer: {
    contador: contadorReducer
  }
});
```

#### Contador.jsx

```jsx
import { useSelector, useDispatch } from 'react-redux';
import { incrementar, decrementar } from '../redux/features/contadorSlice';

function Contador() {
  const valor = useSelector(state => state.contador.value);
  const dispatch = useDispatch();

  return (
    <div>
      <h2>Contador: {valor}</h2>
      <button onClick={() => dispatch(incrementar())}>+</button>
      <button onClick={() => dispatch(decrementar())}>-</button>
    </div>
  );
}

export default Contador;
```

---

## 🔧 Resumen

* RTK simplifica y organiza mejor el código.
* No necesitas crear archivos separados para acciones.
* Reducers más fáciles de leer.
* Mutaciones seguras (gracias a `immer`).
* Ideal para proyectos medianos o grandes.
